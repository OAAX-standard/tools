# Contributing to OAAX examples

Thank you for your interest in contributing to OAAX tools! We welcome contributions from the community to improve the utility tools needed when dealing with OAAX and make them more useful for everyone.

Before you start contributing, please take a moment to read through [OAAX general CONTRIBUTING document](https://github.com/OAAX-standard/OAAX/blob/main/CONTRIBUTING.md). It sets out the guidelines for contributing to OAAX projects, including code style, commit message format, and other important information.

## How to contribute

OAAX tools are designed to be easy to use and understand. If you have an idea for a new tool, would like to improve an existing one, have suggestions for enhancements, or report bugs, please follow these steps:
1. **Open an issue** in the repository to discuss your idea or improvement.
2. **Fork the repository** and create a new branch for your changes.
3. **Make your changes** and commit them with a clear message.
4. **Push your changes** to your forked repository.
5. **Submit a pull request** to the main repository for review.

## Contribution ideas

If you're looking for ideas on what to contribute, here are a few suggestions:

### Additional measurement tools
Add additional measurement tools that can be used to analyze the performance of OAAX runtimes and toolchains. This could include tools for measuring CPU usage, memory usage, or other performance metrics.

### Statistics Visualization layer
Add a visualization module that can be used to visualize the results of the measurement tools. This could include graphs, charts, or other visual representations of the data collected by the tools.

### Model visualization layer
Add a visualization module that can be used to visualize the output of models used in OAAX runtimes. This could include tools for visualizing object detection bounding boxes, segmentation masks, or other model outputs.

### Input retrieval layer
Add a module that can be used to retrieve input data for the models used in OAAX runtimes. This could include tools for retrieving images, videos, or other data types from various sources.
